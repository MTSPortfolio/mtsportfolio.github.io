Where I'm useful

Financial modelling

Portfolio theory, DCF, IRR and NPV — implemented as tested code rather than a spreadsheet, so the numbers are reproducible and the assumptions are explicit.

My day job: turning telco data into metrics people make decisions with. SQL, Python, and dashboards that answer a question instead of showing everything at once.

Web applications

FastAPI with HTMX and Tailwind — server-rendered, no SPA and no JavaScript build step. The calculation engine stays pure Python, testable on its own.
